# Novabrands — Premium Headwear

Catálogo e-commerce de gorras premium, desarrollado por **Lemustech Co.** El catálogo se gestiona con Firebase, así los productos se mantienen actualizados sin tocar código.

## ✨ Características

- 🧢 **Catálogo en línea** de gorras premium
- ☁️ **Datos en la nube** con Firebase: catálogo siempre actualizado
- 📱 **Diseño responsive** pensado primero para el teléfono del cliente
- ⚡ Carga rápida en una sola página (single-page)

## 🛠️ Stack tecnológico

- HTML5 + JavaScript
- Tailwind CSS
- Firebase
- Font Awesome
